## State Management Pattern

All new client components follow the existing MeowNet pattern:
- Local `useState` for UI state
- Server Actions for mutations (no client-side API calls)
- Supabase Realtime for live updates (where applicable)
- Optimistic UI via `useOptimistic` (React 19)
- `useTransition` for non-blocking state updates
