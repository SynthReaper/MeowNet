## Volunteer Management API

### `GET /api/volunteers/availability`
Returns availability slots for the authenticated user or a given userId (mod/admin).

**Auth:** Required  
**Query:** `?userId=<uuid>` (optional, mod/admin only)

**Response:**
```json
{
  "availability": [
    { "id": "uuid", "day_of_week": 1, "start_time": "09:00", "end_time": "17:00", "is_active": true }
  ]
}
```

### `POST /api/volunteers/availability`
Sets/updates availability slots.

**Auth:** Required  
**Body:** `{ day_of_week: number, start_time: string, end_time: string, is_active: boolean }`

---

### `GET /api/volunteers/skills`
Returns skills for authenticated user.

**Auth:** Required

### `POST /api/volunteers/skills`
Claims a skill (pending verification).

**Body:** `{ skill_type: SkillType }`

### `PUT /api/volunteers/skills/[id]/verify`
Verifies a volunteer's skill. **Moderator/Admin only.**

---

### `GET /api/volunteers/tasks`
Returns task board items with filters.

**Query:** `?status=open&colony_id=<uuid>&priority=high&skill=tnr_assistant`

### `POST /api/volunteers/tasks`
Creates a new task. **Moderator/Admin only.**

### `PUT /api/volunteers/tasks/[id]/claim`
Claims a task.

### `PUT /api/volunteers/tasks/[id]/complete`
Completes a task. Accepts multipart form for verification photo.

---

### `POST /api/volunteers/hours`
Logs volunteer hours.

**Body:** `{ colony_id: string, activity_type: string, hours: number, date: string, notes?: string }`

### `PUT /api/volunteers/hours/[id]/verify`
Verifies logged hours. **Moderator/Admin only.**

---

### `GET /api/volunteers/matching`
Returns ranked colony matches for authenticated volunteer.

**Query:** `?colony_id=<uuid>`

**Response:**
```json
{
  "matches": [
    { "volunteer_id": "uuid", "match_score": 0.87, "distance_km": 2.3, "matching_skills": ["tnr_assistant"] }
  ]
}
```

### `POST /api/volunteers/dispatch`
Dispatches a volunteer to an incident. **Moderator/Admin only.**

**Body:** `{ incident_id: string, volunteer_id: string }`

## Emergency API

### `GET /api/emergency/incidents`
Returns incidents with optional filters.

**Auth:** Required  
**Query:** `?severity=critical&status=open&within_km=5&lat=<number>&lng=<number>`

### `POST /api/emergency/incidents`
Reports a new incident. Accepts multipart form with photo uploads (EXIF stripped).

### `PUT /api/emergency/incidents/[id]/acknowledge`
Acknowledges an incident. **Moderator/Admin only.**

### `PUT /api/emergency/incidents/[id]/resolve`
Resolves an incident with notes. **Moderator/Admin only.**

---

### `GET /api/emergency/alerts`
Returns active alerts for the user's region.

**Auth:** Required  
**Query:** `?lat=<number>&lng=<number>&radius_km=5`

---

### `POST /api/emergency/contacts`
Adds an emergency contact.

### `GET /api/emergency/contacts`
Returns the authenticated user's emergency contacts.

## Supply API

### `GET /api/supplies/inventory`

**Query:** `?category=food&lat=<number>&lng=<number>`

### `POST /api/supplies/inventory`

### `POST /api/supplies/requests`
Creates a supply request.

### `PUT /api/supplies/requests/[id]/approve`
Approves a supply request. **Moderator/Admin only.**

### `PUT /api/supplies/requests/[id]/fulfill`
Marks a supply request as fulfilled.

## Education API

### `GET /api/education/courses`
Returns published courses.

**Query:** `?category=basic_tnr&difficulty=beginner`

### `POST /api/education/courses`
Creates a course. **Admin only.**

### `POST /api/education/enrollments`
Enrolls authenticated user in a course.

### `PUT /api/education/enrollments/[id]/progress`
Updates course progress.

### `POST /api/education/enrollments/[id]/quiz`
Submits quiz answers and scores.

**Body:** `{ answers: Record<string, string> }`

### `GET /api/education/certificates/[id]`
Generates/downloads a PDF certificate for a completed enrollment.

## Analytics API

### `GET /api/analytics/welfare`
Returns welfare score time-series for colonies.

**Query:** `?colony_id=<uuid>&from=<date>&to=<date>`

### `GET /api/analytics/population`
Returns population estimates (rules-based for v0.9.0, ML in v1.0.0).

### `GET /api/analytics/impact`
Returns aggregate impact metrics (TNR count, adoption rate, volunteer hours).

## Research API

### `POST /api/research/requests`
Submits a research data request.

### `GET /api/research/export/[id]`
Exports anonymized data for an approved request. **Admin approval required.**

**Security:** Export contains NO GPS coordinates, NO user UUIDs, NO personally identifiable data. Aggregate statistics only.
