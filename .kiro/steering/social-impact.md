## Mandatory Security Gates (All New Features)

1. `supabase.auth.getUser()` at top of every Server Action and API route
2. Role read from DB (`profiles.role`) — never from client JWT claims
3. EXIF stripping via `lib/security/exif.ts` before any photo upload
4. `sanitizeText()` applied to all new user string inputs
5. GPS not stored raw — DB trigger `snap_to_grid()` handles fuzzing
6. Empire Points via `award_points` RPC only — no direct INSERT into `point_log`
7. UUID params validated before DB calls
8. Research data exports: anonymized only (no GPS, no UUIDs, aggregate stats)

## Mobile-First Mandate (Field Use Pages)

The following pages are primarily used in the field on mobile:
- `/emergency` — Incident reporting
- `/volunteers` — Task claiming and hour logging
- `/supplies` — Supply requests

These pages MUST:
- Have tap targets ≥ 48px
- Work offline via optimistic UI
- Load above-the-fold content in ≤ 1s
- Use minimal form steps (max 4 per workflow)

## Design Constraints

All new UI inherits the existing MeowNet design system:
- Primary palette: `--empire-cream`, `--empire-gold`, `--life-teal`
- All cards: glassmorphism (`bg-white/5 backdrop-blur-md`)
- All transitions: `0.3s ease-out` minimum
- No emoji characters in TSX/TS source
- `prefers-reduced-motion` support on all animations
